# Conocimiento del plugin desarrollo-odoo

`protocolo-senior.md` fija la forma de pensar. `api-por-version.md` lista los cambios de API y de vistas entre versiones que rompen módulos. `estandares-codigo.md` resume las convenciones de la OCA y de Odoo que hacen un módulo mantenible. `apps-store.md` reúne lo que exige la tienda de aplicaciones de Odoo para publicar y vender. `licencias.md` explica las licencias y su compatibilidad. `pruebas.md` cubre pruebas automatizadas. `owl.md` resume el cliente web moderno. `patrones-codigo.md` cataloga defectos frecuentes en módulos propios y de terceros (K-01 a K-16).

Regla: cada afirmación sobre una API se confirma en el código fuente de la rama exacta o en la documentación oficial de esa versión antes de usarla; lo confirmado se anota en `CAMBIOS.md` del plugin de consultoría con fecha.
