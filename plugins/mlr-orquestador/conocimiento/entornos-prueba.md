# Entornos de prueba de MLR por versión

Regla: ninguna prueba, demostración, desarrollo o verificación de una funcionalidad se hace en la base de producción de un cliente. Cuando no hay base del cliente, o cuando lo que se va a probar no debe tocarla, se usa el entorno de prueba de MLR de la misma versión y edición; el orquestador y cada agente lo sugieren por defecto y entregan el enlace, la base y el acceso. Los entornos viven en el servidor de MLR en Oracle Cloud (159.54.130.123); el acceso general es el usuario direccionjm@mlrconsultores.com con la contraseña MLR2026# (inventario actualizado al 2 de octubre de 2026; fuente: `MLR Odoo\Ambientes Locales Odoo\Accesos-ambientes-Odoo.xlsx`).

Entornos estándar (Odoo Enterprise sin código de cliente, localización mexicana, plan de cuentas MX y moneda MXN):

Odoo 16: base v16s_pruebas en https://odoo16.159-54-130-123.sslip.io/web/login?db=v16s_pruebas, 54 aplicaciones, rama oficial 16.0 actualizada cada madrugada. Odoo 17: base v17_pruebas en https://odoo17.159-54-130-123.sslip.io/web/login?db=v17_pruebas, rama oficial 17.0 actualizada cada madrugada. Odoo 18: base v18_pruebas en https://odoo18.159-54-130-123.sslip.io/web/login?db=v18_pruebas, 58 aplicaciones, versión fija (paquete del 30 de septiembre de 2026). Odoo 19: base v19c_pruebas en https://odoo19.159-54-130-123.sslip.io/web/login?db=v19c_pruebas, 61 aplicaciones, versión fija (paquete del 30 de septiembre de 2026). Odoo 20 fija: base v20_pruebas en https://odoo20.159-54-130-123.sslip.io/web/login?db=v20_pruebas, 64 aplicaciones; aquí se probó el circuito de CFDI con un RFC real (59 CFDI descargados del SAT convertidos en facturas borrador): contiene comprobantes reales y no se comparte fuera de MLR ni se usa en demostraciones. Odoo 20 viva: base v20l_pruebas en https://odoo20-vivo.159-54-130-123.sslip.io/web/login?db=v20l_pruebas, al día con la rama oficial 20.0, se actualiza cada madrugada y puede romperse con cambios de Odoo; es el entorno para probar lo último.

Réplicas de clientes (solo para ese cliente y bajo su acuerdo de confidencialidad):

Saguapac, Odoo 16: v16_saguapac_espejo en https://saguapac-16.159-54-130-123.sslip.io/web/login?db=v16_saguapac_espejo es la réplica con la migración desde Oracle (plan de cuentas boliviano, moneda BOB, 856 cuentas y 6,593 contactos) y la base principal para las pruebas del corte del 3 de noviembre; el código se sincroniza con los repositorios de Saguapac cada quince minutos. v16_saguapac (misma dirección con db=v16_saguapac) es la base original casi vacía con los módulos instalados. v16_saguapac_espejo_pruebas_ui (db=v16_saguapac_espejo_pruebas_ui) es la copia para pruebas de interfaz con unos 205 asientos de prueba. v16_saguapac_espejo_descartada está dañada de origen (módulo de Gastos a medias), solo consulta, no usar para pruebas; en ella no existe el usuario de dirección y el acceso es el administrador del cliente. Quimibond, Odoo 19: v19_pruebas en https://quimibond-19.159-54-130-123.sslip.io/web/login?db=v19_pruebas, base de pruebas de MLR sobre una copia local del código de Quimibond, 63 aplicaciones, código fijo que no se actualiza.

Reglas de uso: elegir el entorno de la misma versión mayor y edición que el cliente; para novedades, la 20 viva; lo que se cree en un entorno estándar se nombra con el prefijo del cliente o de la prueba y se borra o documenta al terminar; los entornos que se actualizan cada madrugada pueden cambiar de comportamiento, así que una prueba que falle se repite antes de concluir; la contraseña se comparte solo dentro de MLR y nunca aparece en entregables ni en capturas; cuando un cliente necesita su propio entorno se duplica su base neutralizada en lugar de usar los de MLR; cualquier alta, baja o cambio de entorno se anota aquí y en el Excel de accesos con fecha.

Entornos propios del consultor: pendiente de crear en una cuenta personal, uno por versión, para pruebas de módulos propios, contribuciones y certificaciones; cuando existan se registran en la versión genérica de este archivo.
